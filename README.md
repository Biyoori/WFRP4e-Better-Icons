# WFRP4E - Better Icons

A Foundry VTT module that enhances icons for the Warhammer Fantasy Roleplay 4th Edition system.

## Features

- **Automatic Icon Replacement**: Automatically replaces skill and talent icons with better, more thematic versions
- **Skill Icons on Character Sheets**: Displays icons next to skill names on character sheets
- **Compatibility**: Works with both character and NPC actor types

## Requirements

- **System**: WFRP4e (Warhammer Fantasy Roleplay 4th Edition) version 8.0+
- **Module**: wfrp4e-core
- **Foundry VTT**: Version 12+

## For Content Creators

If you want to add your own icons:

1. **Skills**: Add SVG files to `icons/skills/` using the format `skillname.svg`
2. **Talents**: Add PNG files to `icons/talents/` using the format `talent-name.png`

The module will automatically detect and apply new icons when items are created.
